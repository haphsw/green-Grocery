Green Grocery website

1.Problems green grocery solves
Green Grocery Website was developed to help customers easily access information about fresh fruits, vegetables and other grocery products online. 
-It also allows customers to view available products, learn about the different groceries and contact the grocery store without visiting physically

2.How each webpage addresses the problem.
Home-Introduces Green Grocery, provides navigation to all pages and shows featured products
About-Gives information about the grocery business, its mission, vision and objectives.
Products-Displays available grocery products with their categories, prices and availability.
Gallery-Shows fresh fruits and vegetables using images, video, audio and an embedded video.
Contact-Allows customers to send inquiries using an HTML form.

3. How client/server concepts are applied
-The website uses the client/server architecture. The client is the web browser used by customers to access the website while the server stores the website files and sends them to the client when requested.
Then the browser displays the web pages to the user.

4. Web Programming Languages Used include:
HTML (HyperText Markup Language)-is used to create the structure of the website pages.
CSS (Cascading Style Sheets)-is used to improve the appearance of the website. It controls colors, fonts, spacing, backgrounds, and page layout.
JavaScript-is used to add interactivity to the website. It is used for functions such as button actions and form validation.

5. Web Hosting Concept
Shared Hosting- is a hosting method where multiple websites share resources from the same server. It is suitable for a small grocery website because it is affordable and easy to manage.
Application Server -it processes client requests and delivers dynamic web content and also supports web applications that require server-side processing.
Dedicated Server -provides all server resources to one website and offers better performance and security for the websites that have many users.

6. Emerging trends in Internet Programming
The Green Grocery Website can adopt modern Internet programming trends such as:
-Single-page applications for faster user interaction.
-Integration with Web APIs for online payments and delivery tracking.

7. Javascript Functionality
Interactive buttons that display messages to users.
Dynamic interaction between users and the website.

Conclusion
Green Grocery provides customers with easy access to grocery information and product details.
It also demonstrates concepts such as client/server architecture and multimedia integration in web development.
